## 下一阶段的第一件事

用户选一个角色和一种明确形态，并提供同一敌人招式下的普攻、早闪/晚闪、成功触发超算及消球录像。可分短片。AI 登记样本条件，先填一组能复跑的“普攻 → 闪避 → 恢复”时间区间。在 UE 中以原创占位动作做同样用例，再扩展球列和敌人反馈。具体采样见 [测量方案](research/measurement.md)，开发顺序见 [架构草案](architecture.md)。

跨设备接手先核对远端 main 与本地 HEAD，读 AGENTS.md 和本页，再按 [环境说明](environment.md) 编译并进行空地图启动检查。每个阶段结束更新本页与验证记录，将可复用的证据和决策分别写回对应文档。
