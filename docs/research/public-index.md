# 本机索引与反馈资源证据

采样日期 2026-11-18，PC 安装包版本 4.9.1。下面的数量来自直接读取标准容器和元数据。本文仅记录统计量、少量字段标识和分析边界。

## 两份能直接读取的索引

以游戏数据目录下的 `PGR_Data/StreamingAssets/resource/` 为起点。

| 索引 | 实测格式 | 索引映射 | 可读逻辑名 |
| --- | --- | ---: | --- |
| `launch/index` | UnityFS v8，1 个 LZ4HC 数据块 | 19 项 | 1 个 ACF |
| `matrix/InPkgIndex` | UnityFS v8，51 个 LZ4HC 数据块 | 84,757 项 | 2,561 个 ACB、1,862 个 AWB、509 个 USM |

二者均声明 Unity 2022.3.52f1c1。每个目录只列出一个 CAB 序列化文件，每个文件含一个 AssetBundle 和一个 TextAsset。两个 TextAsset 字段分别为 1,488 和 6,592,511 字节，均按标准 MessagePack 成功解码为六元素数组，只有第一个元素是非空映射，其余五项为 null。这是索引记录数，与整个安装清单的文件数用途不同。

17 + 79,824 条 UAB 记录的键全部呈 16 位十六进制文件名，其记录中的逻辑名字段全部为空。两个不带扩展名的十六进制键在逻辑名字段也为空。由此可复验索引覆盖的文件类型、数量和部分音视频的原逻辑名。角色到动画、技能表、AI、镜头或 HUD 预制体的对应关系仍然缺失。未将十六进制名称认定为特定哈希算法，也未尝试逆推。

## 从名称走到元数据实证

索引提供逻辑名到本地文件名的对应关系。通过这层映射，只读检查三个 ACB 的明文 `@UTF` 根表、嵌套 `CueNameTable` 及其 CueName 字段。没有导出声音。

| 抽样音库 | Cue 行数 | 已实际读取的证据与用途 |
| --- | ---: | --- |
| 通用 UI（`g_ui`） | 95 | 存在技能反馈 cue，名称包含 `skillsingle` 和 `skillthree`。为参照录像的技能反馈分类提供线索。 |
| 通用战斗（`g_ingame_tongyongfight`） | 31 | 分别存在名称带 `shieldbreak` 和 `tongyongjiaqiu` 的 cue。可在实机录像中核查破盾、加球时的反馈。 |
| `e_signal` | 7 | 七个名称均含 `signal_attack`。单凭 signal 一词无法确定与信号球消除的关系。 |

Cue 名称不能确定由哪个输入、状态、脚本或角色触发，也不能据此判断游戏缺少二消、破盾的数值条件或反馈延迟。

509 条 USM 逻辑名里，24 条以 `External/Video/simulatetrain` 起始。逐个读取这 24 份 CRID 文件的明文视频流头，得到下列**编码标称帧率**。

| 数量 | 流头分辨率 | 帧率 |
| ---: | --- | ---: |
| 11 | 1920 × 1080 | 60 fps |
| 8 | 854 × 480 | 30 fps |
| 5 | 四种尺寸，宽 1502–1508，高 842–852 | 25 fps |

本轮没有解码、观看或导出这些视频。名称提供训练演示候选，画面中是否含目标角色、HUD、可见命中或实际交互未知。标称帧率也不能证明每帧都是独立的引擎采样。后续优先按角色选择自录训练场素材，保留输入参照、帧率记录和重复对照。若能在游戏正常播放的教学内容中找到同类片段，可用于对照动作外观。剪辑或无输入标记的片段不能测定输入接收窗口。

## 在另一台电脑复验

脚本从安装根目录定位两份标准索引，默认输出两行聚合 JSON。加 `--media-headers` 时额外核对三份音库 Cue 表及上述命名前缀的视频流头。工具只读本地安装，输出到控制台，遇不支持的格式或字段会报错。无需启动游戏。

```powershell
# PGR_CLIENT_ROOT 指向含 PGR.exe 的本机目录。从仓库根目录运行
python -B tools/inspect_public_index.py "$env:PGR_CLIENT_ROOT" --media-headers
```

本机实测 Python 3.14.7，可用已安装的 `msgpack` 或 pip 随附的 MessagePack 读取器。本机实际走 pip 的离线后备路径。若两者均缺失，使用项目外的虚拟环境安装标准 `msgpack` 包后重试。客户端升级后若布局变化，应在新版本上再次检查，并保留此版本的记录。
