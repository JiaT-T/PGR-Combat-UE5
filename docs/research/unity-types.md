# 散装资源里的对象与战斗线索

2026-11-18 对本机样本做了两次只读检查，先读标准 Unity 对象目录，再聚合动画名和脚本类型名。客户端的类型元数据中有技能球、超算状态、时间控制、战斗镜头和受击概念。目录没有提供这些概念之间的调用关系、角色技能表或可直接用于 UE5 的时序参数。

## 样本与复验

在仓库根目录执行以下命令，`PGR_DATA` 指向这台电脑上的游戏 `PGR_Data` 目录。工具仅用 Python 标准库，已在 Python 3.14.7 上运行完成。

```powershell
python tools/inspect_unity_types.py "$env:PGR_DATA"
python tools/inspect_unity_types.py --classify-names "$env:PGR_DATA"
```

两次都成功处理 11 个文件。脚本核对声明文件长度、元数据和对象边界、类型索引。仅支持带 48 字节扩展头、类型树已剥离的 v22 散装文件。11 份样本的引擎版本字符串均为 `2022.3.52f1c1`。名称筛查仅支持 2022.3 播放器对象，读取 AnimationClip 的名称和 MonoScript 的名称、类名、命名空间、程序集标识。输出是计数。没有载入游戏、执行脚本、读取方法体、导出动画曲线或打开封装资源。

| 目录根下文件 | 对象数 | 可复核的观察 |
| --- | ---: | --- |
| globalgamemanagers | 18 | 18 个引擎全局设置对象 |
| globalgamemanagers.assets | 7,449 | 7,447 个 MonoScript（ID 115），另有材质及预加载数据各 1 个 |
| level0 / level1 | 28 / 51 | 分别有 6 / 12 个 GameObject、7 / 13 个 MonoBehaviour。level1 有 1 台 Camera |
| level2 / level3 | 5 / 5 | 各含 5 个场景设置类对象，没有 GameObject |
| resources.assets | 2,446 | 547 个 GameObject、594 个 MonoBehaviour、3 个 AnimationClip、4 个 Animator、3 台 Camera、3 个 SphereCollider、16 个 Canvas、440 个 RectTransform、6 个 TextAsset |
| sharedassets0 / 1 / 2 / 3.assets | 2 / 4 / 1 / 1 | 预加载数据与少量材质、纹理 |
| **合计** | **10,010** | 此范围未见 AnimatorController（ID 91）或 AnimatorOverrideController（ID 221） |

3 个动画片段名称均未命中工具内有限的攻击、移动和界面词表，因此不能将其中任何一个归属到目标角色或招式。SphereCollider 的类型同样不能证明其用途是攻击判定。

另对 6 个 TextAsset 检查了标准名称和至多 128 字节的格式前缀。6 个名称都没有命中战斗词。4 个前缀为普通可打印文本，未读取其余正文。另 2 个符合 JSON 起始特征，均小于 64 KiB，实际解析为 JSON 对象。浅层字段类别中，1 个有图形、渲染或设备术语，另 1 个未命中选定类别，两个都没有命中判定体、技能 ID、攻击帧、冷却或信号球字段词表。当前没有可以作为战斗参数表使用的样本。以上统计可用同一条 `--classify-names` 命令复验。

## 哪些类型名确实指向战斗

`globalgamemanagers.assets` 的 7,447 条 MonoScript 是类型引用元数据。其中 4,966 条属于默认播放器程序集，657 条被工具的已知引擎程序集前缀命中，其余 1,824 条保留为其他程序集。默认播放器程序集也可以包含第三方类型。下表只统计默认播放器程序集中的类名。术语按完整驼峰分词匹配，UI 标记同时检查类名和命名空间，表中各行可以重叠。计数单位是元数据条目，不代表场景实例、角色数或机制数。

| 方向 | 实际名称证据 | 仍需验证 |
| --- | --- | --- |
| 技能与状态 | 技能＋动作 5 条、技能＋帧 2 条、技能＋状态 3 条 | 没有角色与动作的映射、输入门槛或起止帧 |
| 技能球 | 技能球相关 5 条，其中 1 条有 UI 标记，另见管理与加球处理语义 | 发球顺序、邻接规则以及一消、二消、三消的结果 |
| 超算与时间 | 超算语义 4 条，其中 2 条同时有状态语义。时间伸缩 4 条、时间倍率 3 条 | 是否由特定闪避触发、超算如何使用这些类型、倍率和受影响对象 |
| 无敌与闪避 | 无敌语义 2 条。独立的闪避词未命中本词表 | 无敌的拥有者与来源、受击无效的起止边界 |
| 连段与取消 | 唯一连段词命中同时带有战斗 UI 标记 | 可能显示连击数。无法据此确定攻击链、后摇或取消窗口 |
| 命中、受击与移动 | 战斗＋碰撞体 1 条、受击 3 条、根运动 1 条 | 判定形状与采样时机、顿帧时长、特定招式的实际位移 |
| 镜头与 HUD | 战斗＋相机 1 条、命中＋相机＋轨道 1 条、战斗＋UI 212 条 | 实际启用条件、锁定或震屏策略、HUD 状态更新来源 |
| 敌人 AI | 行为树 18 条。未找到同时包含敌人或 NPC 与独立 AI 词的条目。含 NPC 与瞄准词的名称已排除 | 具体敌人是否绑定这些行为树、攻击选择、距离阈值与决策频率 |

本批样本最适合帮助挑选观察对象。例如给同一次完美闪避标记角色、敌人和 HUD 的时间变化，给不同消球输入标记球列与动作响应。后续需要用独立录像或经用户确认的实机对照，将具体行为和数值升级为已验证机制。

公开类型编号可对照 [Unity 2022.3 Class ID Reference](https://docs.unity3d.com/2022.3/Documentation/Manual/ClassIDReference.html)。
