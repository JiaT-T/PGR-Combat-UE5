# 七实·芒星之迹的网页动作与录像对照

2026-11-19，研究范围为 Huaxu 中文模型页打开时默认选中的 **泛用式·终**，页面标识为七实·芒星之迹 / MPL-00。本次在浏览器中加载了 3D 预览，选择 Fight、切换动作层、实际播放红球与两种必杀，并对照该涂装的公开清单。录像 V02 的角色阶级由用户确认为 SSS，录像使用哪套涂装尚未核实。[角色模型页](https://huaxu.app/cn/wiki/constructs/mang-xing-zhi-ji/model) · [默认涂装清单](https://assets.huaxu.app/models/charaterprefab/r5yongyechaomd010031/manifest.json)

## Attack40–48 的动作衔接

**玩家指认的输入锚点。** 红球首次与再次输入分别为 Attack11、12，蓝球为 Attack21、22。点黄为 Attack31，长按黄为 Attack32。剑盾普攻为 Attack01–04，点黄切入盾斧后的普攻为 Attack61–64，盾斧长按普攻对应 Attack99。剑盾必杀为 Attack51，盾斧必杀为 Attack52。上表保留网页分组和录像证据，以下使用玩家指认来定位操作。

**默认涂装的姿势核验。** 在浏览器 Fight 预览中分别查看九个片段。另取这九项、Attack31/32、Attack61–64、Attack99 和两层 Stand2，一共 18 项。比较其中共同的 73 条局部旋转轨，对每个对应采样计算两姿势的最小角差。表内“小于 0.2°”表示两片段端点或指定采样之间的相似度。数值仅度量这批轨道，根移动、武器特效、引擎状态与混合时刻需另看。

| 编号 | 片段时长 | 预览及姿势比较所得 |
|---|---:|---|
| Attack40 | 3.83 秒 | 收到剑盾待机姿势。当前录像缺少可唯一归属的输入或姿势 |
| Attack41 / 42 | 2.77 / 3.90 秒 | 两者都收回盾斧待机。41 播到约 0.97 秒时与 42 起势的平均差约 0.94°，根位置也吻合。可能从 41 的中途转 42 |
| Attack43 / 44 / 45 | 0.53 / 1.50 / 2.07 秒 | 43 末与 44 首、45 首均为 73/73 条轨小于 0.2°。44 可见侧身抬膝，片段内部约每 10 帧（0.33 秒）重复一次小幅动作，间隔 10 帧的姿势平均角差约 0.24°。44 末与 45 首有 60/73 条轨小于 0.2°。45 由低姿收回盾斧待机。分别适合作为第一段的进入、维持和退出候选 |
| Attack46 / 47 / 48 | 0.87 / 1.50 / 3.73 秒 | 46 转身前倾，47 明显俯身屈腿，首尾平均角差约 8.57°，尾姿对上 48 起势。48 展身并收回剑盾待机。46 末与 47 首、47 末与 48 首各有 72/73 条轨小于 0.2°。网页战斗转换表另列 48 可接 Stand2 |

45 末与 46 首也很接近，但二者均接近公共盾斧待机。45 在约 0.57 秒与 46 在约 0.30 秒还有一对非待机姿势很近（平均差约 0.49°），相邻采样的平均差又超过 10°。可保留为中途切换的候选点，实际触发条件未知。44、47 的根位置在片段内变化极小，48 的根净位移方向与 43、45、46 相反，和录像最后退离相容。44、47 的清单均标为不自动循环。单看持续的切割特效无法区分片段重播、保持某个姿势或混合。Attack32 的末帧回到剑盾待机，未定位从其播放中段进入 43 或 46 的实机切点。

**对照长按黄球。** V02 在 F1845（61.50 秒）出现黄球触点。约 61.90–63.80 秒第一次接敌并持续切割。63.90–64.50 秒轮刃抬高，七实和敌人拉开。64.60 秒再抬轮，64.67–66.00 秒贴回并出现大金弧。F1984（66.13 秒）发生爆闪，随后七实腾空向后退出，约 66.80 秒已与敌人拉开。F1984 及 F1989（66.30 秒）仍能看到黄球触点。V01 在 42.57–45.27 秒也有抬轮、拉开、二次接敌、爆闪退离的次序。V01 无可见触点。综合姿势与两段录像，43–45 对应第一段、46–48 对应第二段是当前候选。实机两个阶段之间的具体切帧及各片段是否完整播放仍待确认。末段爆闪发生时触点仍可见。

**对照盾斧长按普攻。** V02 约 43.60 秒跃起收腿，44.77 秒竖刃下砸。V01 在 23.60 与 24.77 秒重现，两标志相隔约 1.17 秒。Attack42 的预览在约 0.78 秒腾空提膝、1.95 秒双脚分开下压，间隔相近。录像的落地爆光遮住双脚，Attack99 自身也有大幅离开基准姿势再回落的轨迹。41 是否在其前播放、42 与玩家所指 Attack99 的关系仍未由录像确定。

### 2026-11-19 · 国服专用模式的全量建表结果

**结论。** 在这份 PC 4.9.1 安装包及本机更新中，AnimeStudio 的国服模式未定位到可归属七实·芒星之迹的 AnimationClip、Animator 或角色动作包，无法从该结果列全默认涂装的动画。网页公开的片段和录像姿势仍保留各自的证据来源。

沿用上述 CLI 版本，对仓库外的临时副本执行以下命令。全量测试不设名称、类型或角色筛选条件。每批验证返回码、JSON 的 `GameType` 以及输入文件名与逐文件处理日志是否一一对应。

共 87 批，输入总量 36,649,421,863 字节，全部退出 0。表中按实际文件计数，同名的安装包与更新副本分别测试。新增的 2,346 个更新目录 .uab 也逐一核实了 HARUINKURO 前缀。

**阳性对照。** 国服模式从 11 个散装 Unity 文件列出 870 项，包含前述 3 个动画片段和 4 个 Animator。单独读取 resources.assets 时有 845 项，把它的相同字节副本改为十六进制文件名加 .uab 后仍是 845 项，对象类型、名称、PathID 和容器逐项相同。把标准 UnityFS 索引副本改为 .uab 也能列出 TextAsset。因此扩展名本身不能解释客户端包建表为空。额外用 Both 模式检查标准索引和两个实际包，标准索引生成的容器表有可见 CAB 标识，实际包的对象表仍为空。

**索引与归属。** 国服模式从安装及更新目录的 4 份标准 UnityFS 索引各列出 1 个 TextAsset。用项目已有的只读索引工具复核其明文结构，更新索引列出的 17 个 launch 和 80,359 个 matrix 的 .uab 文件名，在安装或更新目录中均能找到，逻辑路径字段全部为空。在该 matrix 索引的结构化字段中按机体名称、角色 ID 和已知别名检索，命中的带名资源只有四种语言的 ACB / AWB 音库。散装对象目录也未出现七实或 Attack 系列的可归属条目。

本轮只建立对象目录，未导出 FBX、动画曲线或模型。空表说明这版 CLI 的这个工作模式没有列出对象，不能据此判定包内没有动画、具体加密方式或其他版本的兼容性。

公开清单有片段时长、帧率、循环与状态关联。抽查 Move1、Attack11、Attack52、Attack61、Attack64 的公开片段数据能读到动画轨道，未见命中、扣球或无敌事件。清单中的混合时间和挂点记录也不足以恢复这些规则。本机 PC 4.9.1 仍缺七实动作到具体资源包的映射。站方说明网页预览有逐帧功能，下载用的 GLB 不含动画与着色器。仓库仅保存测量摘要与来源链接，当前没有可用于 UE 工程分发的原作动作授权记录。[站方的模型查看器说明](https://huaxu.app/blog/model-viewer)
