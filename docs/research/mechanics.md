## 七实长按黄球收刀

2026-11-21，玩家为 Demo 指定收刀规则。长按主键盘 3，在攻击段松手、星芒耗尽或第二段自然结束时，直接播放盾斧回剑盾的最后一个动画。收刀结束后按 J，应从剑盾普攻 `Attack01` 起手。持续按住 3 至收刀结束，本次按压只发动一次焚冲。

**已获得证据**　试玩版代码 `735ac44`、配套资产 `9f7a566` 的长按收刀依次播放 `Attack48`、`Attack45` 和回剑盾动画。最后一段是 `AM_EquippedYellowHold` 的 `ReturnToSword`，使用序列 `YellowReturnSword`（黄球 `Attack32`）。本次玩家校正只取这一段。该对应关系来自 Demo 资产和旧版记录。原作如何调度这些片段仍需实机验证。

## 七实 SSS 的输入与打断规则

2026-11-19 由玩家说明，作为本轮动作流程的依据。

| 操作 | 对下一次输入的影响 |
| --- | --- |
| 进入红球或蓝球二段资格 | 资格持续保留。等待、穿插普攻、闪避或切形态都不会清掉它。唯一退出条件是点击二段红球或蓝球并释放二段技能。SS 可直出二段是另一条升阶规则。[技能说明](nanami-startrail.md) |
| 在当前普攻末段再点普攻 | 衔接窗口缓存下一次普攻输入，用于接下一段。各段窗口的起止时刻留给人工测试和调整，当前没有实测帧值。 |
| 普攻期间使用技能球、闪避或切形态 | 直接打断当前普攻，下一次普攻从届时武器的第一段开始。剑盾从 Attack01 开始，盾斧从 Attack61 开始。 |
| 普攻与大招争用输入 | 大招优先于普攻。技能球、闪避、切形态也各自优先于普攻。这些高优先级动作彼此之间的顺序未指定。 |

截至 2026-11-19，Attack43–48 仍是焚冲两组衔接的候选。本轮 Demo 收刀以 11 月 21 日的玩家校正为准。Attack40–42 按玩家回忆可能属于防反，具体归属待验证。[姿势与录像对照](nanami-motion-assets.md)
